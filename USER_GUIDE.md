# User guide

## Faculty instructions

1. Open the app in the browser.
2. Click Register and create a faculty account.
3. Choose the Faculty role.
4. Log in with your email and password.
5. Enter the course name and room.
6. Click Start Session.
7. Share the QR code with students.
8. Monitor the live attendance list.
9. Click End Session when class is complete.

## Student instructions

1. Open the app in the browser.
2. Create a student account or log in.
3. Enter the student ID.
4. Wait for the faculty to start the session.
5. Click Open Camera.
6. Scan the QR code shown by the faculty.
7. Look at the camera when the selfie step appears.
8. Click Capture & Submit.
9. Wait for the result message.

## Important notes

- Browser camera access must be allowed.
- Use Chrome, Edge, Firefox, or Safari with the latest version.
- The app must run on localhost or HTTPS.
- If the QR is expired, scan the current one again.

## Common issues

### Camera permission blocked

- Click the lock icon in the browser address bar.
- Allow camera access.
- Refresh the page and try again.

### QR not reading

- Move the camera closer to the code.
- Use good lighting.
- Make sure the code is the current active session code.

### Login fails

- Check the email and password.
- Make sure the account exists.
- Use the same role from registration.
